# 动态变化折线图的实现

HomePage 第 3 页（swipeContainer1Pe3）上两个实时折线图：温度图（上，红色）和心率图（下，蓝色）。

## 1. Designer 配置

选中 `dynamicGraph1`（温度）或 `dynamicGraph2`（心率），右侧属性面板：

| 属性 | dynamicGraph1（温度） | dynamicGraph2（心率） | 说明 |
|------|----------------------|----------------------|------|
| Position X / Y | 69 / 0 | 69 / 147 | 图区左上角 |
| Width / Height | 251 / 90 | 251 / 91 | 图区大小 |
| **Y Value Range** Min → Max | 15 → 45 | 40 → 120 | 与代码 `setGraphRangeY()` 一致 |
| Margins Left | **35** | **35** | 给 Y 轴标签留空间 |
| Line Width | 2 | 2 | 折线粗细 |

### Y Axis Labels（Y 轴数字标签）

在 Graph Elements 里添加 **GraphLabelsY**：

- **Position**: Left
- **Interval**: 10（温度）/ 20（心率）——标签间隔
- **Translation**: `<>`（Designer 自动生成 TypedText，占位符）
- **Typography**: 选小字体，如 verdana 12px
- **Color**: 自选

### Horizontal Grid Lines（水平网格线）

在 Graph Elements 里添加 **GraphElementGridY**：

- **Interval**: 3（温度）/ 8（心率）
- **Line Width**: 1
- **Color**: 自选

### 推荐值

| | 温度图 | 心率图 |
|--|--------|--------|
| Y Range | 15 ~ 45 | 40 ~ 120 |
| Y Axis Labels Interval | 10 | 20 |
| Grid Interval | 3 | 8 |

## 2. 遇到的问题及解决

### 问题 1：Designer 生成代码有 Bug → 黑屏/崩溃

**现象**：Designer "Generate Code" 后直接编译烧录，屏幕全黑甚至 hard fault。

**根因**：Designer 有多个已知 bug，每次生成都会重现。

**解决**：创建 `TouchGFX/fix_after_designer.py`，每次 Designer 生成后运行一次，自动修复 8 个问题：

| Fix | 文件 | 修复内容 |
|-----|------|---------|
| 1 | SensorPageViewBase.cpp | 删除重复的 `add(__background)`（导致 hard fault） |
| 2 | FrontendApplicationBase.cpp | 回调类型 `FrontendApplication::` → `FrontendApplicationBase::` |
| 3 | HomePageViewBase.cpp | 补充 `swipeContainer1.setWidth(320)` + `setHeight(240)`（缺失导致黑屏） |
| 4 | HomePageViewBase.cpp | WiFiModalLink 移到构造函数末尾（Z 序修正） |
| 5 | HomePageViewBase.cpp | toggleButton4 回调改为 SensorPage |
| 6 | texts.xml | SensorPage 文本替换为通配符 |
| 7 | Texts.cpp | 字符串表替换为通配符字符 |
| 8 | HomePageViewBase.hpp | **CANVAS_BUFFER_SIZE 4800 → 9600**（见问题 2） |

**每次 Designer 生成后必须运行**：
```bash
cd TouchGFX
python fix_after_designer.py
```

---

### 问题 2：Canvas Buffer 太小 → 黑屏但系统在跑

**现象**：加了 Grid Lines 和 Y Axis Labels 后，系统初始化正常（串口有输出），但屏幕全黑。

**根因**：Designer 生成的 `CANVAS_BUFFER_SIZE = 4800`（[HomePageViewBase.hpp:105](generated/gui_generated/include/gui_generated/homepage_screen/HomePageViewBase.hpp#L105)）。加了网格和标签元素后 4800 不够用，CanvasWidgetRenderer 渲染失败。

**解决**：改为 `9600`（已加入 `fix_after_designer.py` Fix 8）。

---

### 问题 3：用户代码覆盖 Designer 的 setGraphAreaMargin

**现象**：Y 轴标签没地方显示。

**根因**：[HomePageView.cpp](gui/src/homepage_screen/HomePageView.cpp) `setupScreen()` 里写了 `setGraphAreaMargin(0, 0, 0, 0)`，把 Designer 设置的左留白（35px）覆盖掉了。

**解决**：删除用户代码中的 `setGraphAreaMargin` 和 `setGraphRangeY`，让 Designer 生成的基类配置生效。用户代码只做：
- `clear()` 清除演示数据
- 线条颜色覆盖（红/蓝）
- Box 背景 + 边框

```cpp
// 用户代码只保留这些
dynamicGraph1.clear();
dynamicGraph1Line1Painter.setColor(touchgfx::Color::getColorFromRGB(220, 40, 40));  // 红色
dynamicGraph1.invalidate();
swipeContainer1Pe3.add(dynamicGraph1);
```

---

### 问题 4：X 轴数据量太大，刷新太慢

**现象**：`GraphWrapAndClear<100>` 存 100 个数据点，1 秒 1 点 → 100 秒才循环一轮，感觉刷新慢。

**解决**：手动把 `HomePageViewBase.hpp` 中 `GraphWrapAndClear<100>` 改为想要的值（如 `<30>`，即 30 秒一轮）。Designer 每次生成会覆盖，需手工再改。（未加入 `fix_after_designer.py`，用户选择手动改）

```cpp
// HomePageViewBase.hpp
touchgfx::GraphWrapAndClear<30> dynamicGraph1;
touchgfx::GraphWrapAndClear<30> dynamicGraph2;
```

---

### 问题 5：心率线更新比温度线慢

**现象**：温度线 1 秒 1 个点，心率线好几秒才 1 个点，两条线走势不一致。

**根因**：不是图表问题，是数据源差异。

- SHT20 温湿度传感器每秒都有读数 → `addTempPoint()` 每秒被调用
- MAX30102 心率传感器需要手指就位、采集足够 PPG 数据后才能出有效心率 → `addHRPoint()` 只在 `ch_hr_valid == true` 时才被调用

**结论**：两条线框架参数一致（容量、写入频率），表现差异来自传感器特性，属正常现象。

---

### 问题 6：图表背景颜色和透明度

**现象**：默认背景不够好看，想自定义。

**解决**：在 [HomePageView.cpp](gui/src/homepage_screen/HomePageView.cpp) 的 `setupScreen()` 中设置 Box 的颜色和透明度：

```cpp
// 深蓝半透明背景
graphBg1.setColor(touchgfx::Color::getColorFromRGB(15, 25, 80));
graphBg1.setAlpha(102);  // 40% 不透明度（0=全透明, 255=全不透明）
```

这些 Box 是手动创建的，Designer 不会覆盖。

## 3. 数据流

```
Model::tick()                          [Model.cpp:146]
    └─ modelListener->updateSensorInfo(temperature, humidity, co2, heartRate, spo2)
        │
HomePagePresenter::updateSensorInfo()  [HomePagePresenter.cpp:55]
    ├─ view.addTempPoint(temperature)
    └─ view.addHRPoint((int)heartRate)
        │
HomePageView::addTempPoint()           [HomePageView.cpp:112]
HomePageView::addHRPoint()             [HomePageView.cpp:117]
    │  (缓存到 pendingTemp / pendingHR，置 tempUpdated / hrUpdated = true)
    │
HomePageView::handleTickEvent()        [HomePageView.cpp:82]
    │  tickCounter >= 60 (约 1Hz)
    ├─ dynamicGraph1.addDataPoint(pendingTemp)   → 温度线向右延展
    └─ dynamicGraph2.addDataPoint(pendingHR)     → 心率线向右延展
```

```
TouchGFX Designer 修改 → Generate Code
    → cd TouchGFX && python fix_after_designer.py
    → 手动把 HomePageViewBase.hpp 里 GraphWrapAndClear<100> 改成 <30>（可选）
    → 编译烧录
```
